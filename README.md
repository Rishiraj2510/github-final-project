# Simple Interest Calculator

This project contains a Bash shell script that calculates simple interest based on user input.

## Project Description

The Simple Interest Calculator is a command-line application written in Bash. It allows users to calculate simple interest by entering the principal amount, annual rate of interest, and time period.

## Formula Used

Simple Interest = (Principal × Rate × Time) / 100

## Features

* Accepts user input for principal amount
* Accepts user input for rate of interest
* Accepts user input for time period
* Calculates simple interest instantly
* Easy to run on Linux and Unix-based systems

## How to Run

1. Download the script `simple-interest.sh`
2. Make it executable:

```bash
chmod +x simple-interest.sh
```

3. Run the script:

```bash
./simple-interest.sh
```

## Example

Principal Amount: 1000

Rate of Interest: 5

Time Period: 2 years

Simple Interest = 100
